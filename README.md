# Simple-Calculator

A minimal web-based calculator implemented with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Clickable buttons and simple keyboard input
- Small, dependency-free codebase for easy learning and modification

## Usage

- Click number and operator buttons, then press `=` to get the result.
- You can also type numbers and operators on your keyboard and press Enter.

## Development

- Edit `main.js`, `style.css`, and `index.html` to modify behavior or styles.
